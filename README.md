# Retail Sales Analysis SQL Project

## Project Overview

This project demonstrates the application of SQL skills to analyze retail sales data. It focuses on understanding customer behavior, identifying sales trends, and extracting key business insights. The project showcases the use of structured queries to support data-driven decision-making in a retail environment.

## Objectives

- Clean and preprocess raw retail sales data.
- Perform Exploratory Data Analysis (EDA) using SQL.
- Generate meaningful insights by answering business questions through complex SQL queries.
- Highlight customer purchasing patterns, top-performing products, and seasonal trends.



## Key Concepts Applied

- Data Cleaning and Transformation
- Joins (INNER JOIN, LEFT JOIN, etc.)
- GROUP BY and Aggregate Functions (SUM, COUNT, AVG, MAX, MIN)
- Subqueries and CTEs
- Window Functions (RANK, DENSE_RANK, ROW_NUMBER)
- Date-based Analysis and Filtering
- Customer Segmentation
